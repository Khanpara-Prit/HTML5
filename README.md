# HTML5 Learning Notes

A beginner-friendly HTML reference covering the building blocks of web pages, from the basic document structure to semantic layouts and multimedia. The repository includes both a readable Markdown guide and an HTML file containing examples and a complete sample page.

## Files

- [HTML.md](HTML.md) — the formatted study guide, organized by topic.
- [Index.HTML](Index.HTML) — HTML notes, code examples, and a complete website example.

## Topics covered

- HTML document structure, metadata, and headings
- Text, links, images, and lists
- Tables and forms, including accessible form labels
- Semantic page elements such as `<header>`, `<nav>`, `<main>`, and `<footer>`
- Audio, video, and inline SVG
- A complete example page with navigation, services, portfolio, contact form, and footer

## Getting started

1. Read [HTML.md](HTML.md) for the topic-by-topic guide.
2. Open [Index.HTML](Index.HTML) in a browser or code editor to explore its HTML examples and sample page.
3. Try changing the examples and refresh the browser to see the results.

The sample page references placeholder assets and services (such as images, `styles.css`, `script.js`, and `submit.php`); those files are examples and are not included in this repository.
